# Learning format review — October 7, 2026

Public sources were reviewed; no claims are made about screens behind an authenticated course or paid subscription.

| Source | Observed pattern | Decision in CodePlay |
| --- | --- | --- |
| Mimo homepage and courses | Structured, short coding exercises and project-oriented learning | Short focused quests plus guided mini projects |
| Mimo help: changing learning paths | Separate learning paths selectable by the learner | Separate Free and Pro maps with distinct progress |
| Mimo help: streak challenge | Consecutive-day learning habit | A streak calculated from actual quest completion dates; no purchases |
| Sololearn public homepage | Courses covering several coding subjects | A searchable map grouping Python and Django; no unsupported social or certificate claims |

CodePlay's six exercise types are original implementation choices: multiple choice, code gaps, output prediction, debugging, line ordering and multi-gap guided projects. They should not be understood as a verified inventory of either competitor's current exercise types. No content or artwork was copied from those services.

The free path includes 20 Python foundation quests and 4 broad Django introduction questions. Pro adds 6 advanced Python quests and 14 detailed Django code exercises. Lessons teach one concept at a time, give a hint and explain the result. Projects here are scaffold-completion exercises, not a hosted Django application builder.
